Data da consulta: **2026-10-30**. Método: clone raso (`git clone --depth 1`) de cada repositório e leitura do código-fonte e da documentação. **Nenhum script baixado foi executado.** Estrelas, downloads e popularidade não foram usados como critério.

## Pontos não confirmados nesta rodada (marcados como pendentes)

- Documento oficial da NVIDIA recomendando `OverlayTestMode=5` (MPO): só encontrei fontes comunitárias → ação MPO fica **Condicional, apenas para sintoma de flicker/tela preta**, nunca como otimização de FPS.
- Comportamento atual do `autoexec.cfg` no CS2 (execução automática vs `+exec`): verificar na instalação real.
- Issues dos repositórios: não consegui consultar a API do GitHub neste ambiente (token rejeitado); pesquisa de regressões em issues fica pendente.

# NEXUS — PRODUCT EXPERIENCE MASTER DIRECTIVE
## Simplicidade extrema. Tecnologia avançada. Experiência premium.

A partir de agora, além de atuar como uma equipe de design e engenharia de alto nível, você deverá seguir uma filosofia central de produto:

**O NEXUS deve ser extremamente poderoso por dentro e extremamente simples por fora.**

O usuário não deve precisar estudar o aplicativo, procurar funcionalidades em diversos menus ou entender termos técnicos para obter resultados.

Queremos uma experiência em que qualquer pessoa consiga utilizar o software intuitivamente.

---

# 1. FILOSOFIA: ONE CLICK EXPERIENCE

O princípio mais importante do NEXUS é:

**ABRIU → ENTENDEU → CLICOU → RESOLVEU.**

Sempre que tecnicamente possível, transforme operações complexas em ações simples.

Exemplos:

- Analisar meu PC → um clique.
- Diagnosticar problemas → um clique.
- Identificar gargalos → um clique.
- Verificar drivers → um clique.
- Identificar oportunidades de otimização → um clique.
- Aplicar otimizações seguras → um clique.
- Restaurar configurações anteriores → um clique.
- Preparar o PC para jogar → um clique.

Não obrigue o usuário a navegar por cinco telas para executar uma operação que poderia estar disponível diretamente no dashboard.

Não confunda simplicidade com ausência de funcionalidades. As ferramentas avançadas devem continuar disponíveis, mas não devem atrapalhar a experiência principal.

# 2. DASHBOARD INTELIGENTE

A tela inicial deve funcionar como um centro de controle inteligente.

O usuário precisa visualizar imediatamente:

- Estado geral do computador.
- Saúde e desempenho.
- CPU.
- GPU.
- Memória RAM.
- Temperaturas.
- Armazenamento.
- Drivers.
- Problemas identificados.
- Oportunidades de melhoria.

Apresente as informações em linguagem simples.

Exemplos:

Em vez de:
"CPU utilization: 87%"

Mostrar:
"Seu processador está trabalhando intensamente."

Em vez de:
"Thermal throttling detected"

Mostrar:
"Seu processador está reduzindo o desempenho devido à temperatura."

Em vez de:
"Memory pressure"

Mostrar:
"Sua memória RAM está próxima do limite."

Sempre ofereça uma explicação curta e uma ação recomendada.

# 3. SISTEMA DE OTIMIZAÇÃO ONE CLICK

Criar uma área central chamada:

NEXUS OPTIMIZE

Com um botão principal visualmente destacado:

**OTIMIZAR MEU PC**

Ao clicar:

1. Realizar diagnóstico.
2. Identificar problemas.
3. Analisar configurações.
4. Avaliar oportunidades de melhoria.
5. Classificar ações por risco e benefício.
6. Apresentar o que pode ser melhorado.
7. Aplicar automaticamente somente as otimizações previamente autorizadas e consideradas seguras.
8. Confirmar cada operação.
9. Apresentar o resultado final.

Não aplicar alterações irreversíveis ou potencialmente perigosas sem autorização explícita.

Cada otimização deve ter:
- Nome.
- Explicação simples.
- Benefício esperado.
- Risco.
- Possibilidade de desfazer.
- Estado atual.

Nunca prometa aumento de FPS sem medição ou evidência.

# 4. NAVEGAÇÃO EXTREMAMENTE SIMPLES

Evite excesso de menus, submenus e configurações.

A navegação principal deve ser curta e intuitiva.

Sugestão:

1. Início
2. Otimizar
3. Desempenho
4. Diagnóstico
5. Configurações

As funcionalidades avançadas devem ficar organizadas dentro das respectivas áreas.

O usuário comum não deve ser obrigado a visualizar configurações técnicas complexas.

Adote progressiva divulgação de informações: primeiro mostre o essencial, depois permita expandir para detalhes técnicos.

# 5. IMAGENS REAIS E DIREÇÃO ARTÍSTICA

Quero um aplicativo visualmente impressionante.

Não quero uma interface composta exclusivamente por caixas, textos e ícones genéricos.

Utilize imagens e recursos visuais reais quando agregarem valor:

- Fotografias profissionais de hardware.
- Processadores.
- Placas de vídeo.
- Memórias RAM.
- Computadores gamer.
- Setup gamer premium.
- Texturas e fundos tecnológicos.
- Ilustrações técnicas de alta qualidade.

Utilize imagens com licenciamento adequado, preferencialmente de fabricantes ou bancos de imagens confiáveis.

Não utilize imagens falsas de componentes, especificações inventadas ou imagens que confundam o usuário sobre o hardware detectado.

Quando houver identificação do hardware real, apresente seu modelo e uma imagem correspondente, quando disponível.

As imagens devem ser otimizadas para não comprometer o carregamento.

# 6. MOTION DESIGN E ANIMAÇÕES

O NEXUS deve transmitir tecnologia, precisão e qualidade.

Implemente:

- Animações suaves de entrada.
- Transições entre telas.
- Indicadores de progresso animados.
- Gráficos com animação de atualização.
- Feedback visual ao executar ações.
- Animações de diagnóstico.
- Efeitos sutis de profundidade.
- Microinterações nos botões.
- Estados de sucesso e conclusão.
- Skeleton loading.
- Transições de abertura e fechamento de painéis.

Crie uma animação exclusiva para o processo de diagnóstico.

O usuário deve perceber visualmente que o NEXUS está analisando o computador.

As animações precisam ser fluidas e leves, sem consumir recursos desnecessários da CPU ou GPU.

Respeite a preferência do sistema por movimento reduzido.

# 7. EXPERIÊNCIA PARA QUALQUER PESSOA

Não presuma que o usuário entende de informática.

Toda informação técnica deve poder ser compreendida por alguém que utiliza o computador apenas para jogar, trabalhar e navegar.

Use:
- Linguagem direta.
- Frases curtas.
- Explicações objetivas.
- Ícones reconhecíveis.
- Botões com nomes claros.
- Indicadores visuais.
- Ajuda contextual.

Evite:
- Siglas sem explicação.
- Mensagens de erro incompreensíveis.
- Termos técnicos desnecessários.
- Telas excessivamente carregadas.
- Configurações escondidas.
- Fluxos com etapas desnecessárias.

# 8. DESIGN SYSTEM PREMIUM

Crie uma identidade visual própria para o NEXUS.

Direção:
- Dark premium.
- Sofisticação tecnológica.
- Contraste refinado.
- Tipografia moderna.
- Ícones consistentes.
- Gráficos elegantes.
- Componentes bem dimensionados.
- Hierarquia visual impecável.

O aplicativo deve parecer um produto comercial de uma grande empresa internacional de tecnologia.

Evite copiar diretamente Razer, NVIDIA, MSI ou outros fabricantes.

Inspire-se na qualidade e na maturidade visual dessas marcas, mas crie uma identidade exclusiva.

# 9. INTELIGÊNCIA E PERSONALIZAÇÃO

O NEXUS deve compreender o hardware identificado e adaptar as recomendações.

Exemplos:

- Identificar automaticamente a GPU.
- Identificar o processador.
- Identificar memória disponível.
- Detectar problemas de temperatura.
- Identificar programas consumindo recursos.
- Avaliar inicialização do Windows.
- Detectar drivers desatualizados.
- Identificar possíveis gargalos.

As recomendações devem considerar o equipamento real do usuário.

Não ofereça otimizações genéricas sem verificar se são apropriadas para aquela configuração.

# 10. SEGURANÇA E CONFIANÇA

A simplicidade nunca pode comprometer a segurança.

Antes de qualquer alteração:

- Criar mecanismos de backup quando aplicável.
- Registrar o estado anterior.
- Permitir restauração.
- Verificar permissões.
- Validar se a operação foi executada.
- Exibir erros de maneira compreensível.

Nunca desative mecanismos importantes de segurança do Windows apenas para obter um suposto ganho de desempenho.

Não altere serviços, registro, drivers ou configurações críticas silenciosamente.

O usuário deve saber o que está sendo alterado.
